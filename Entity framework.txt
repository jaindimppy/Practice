Entity framework is an Object Relational Mapping (ORM) framework that offers an automated mechanism to developers for storing and accessing the data in the database.

The Entity Data Model:
(EDM) is an extended version of the Entity-Relationship model which specifies the conceptual model of the data using various modelling technique.
Following are the three core parts of EDM.
The Storage Schema Model = representation of the backend data store.
The Conceptual Model =  we write our queries.
The Mapping Model = mapping between the Conceptual model and the Storage model.

types of entities:
POCO:
A simple, plain class that has no EF-specific behavior.
Suitable for situations where you don't need advanced EF Core features like lazy loading.
They don't need to inherit from any specific base.

Proxy:
A subclass of your POCO created dynamically by EF Core at runtime.
Provides additional behavior like lazy loading, change tracking, and automatic loading of navigation properties.
used for lazy loading


Detached
Description: An entity is in the Detached state if it is not being tracked by the DbContext. This can happen if the entity has not been loaded by the DbContext
When an entity is newly created.

Unchanged
Description: An entity is in the Unchanged state if it is being tracked by the DbContext and its values are the same as what is in the database.

Added
Description: An entity is in the Added state if it has been added to the DbContext and is being tracked, but it has not yet been persisted to the database.
 EF Core will treat the entity as new and will insert it into the database when Save Changes is called.

Modified
An entity is in the Modified state if it has been loaded from the database or added to the context, and its property values have been changed.
EF Core tracks the changes made to the entity and will generate an UPDATE SQL query when Save Changes is called.

Deleted
Description: An entity is in then Deleted state if it has been marked for deletion but has not yet been removed from the database.
EF Core will generate a DELETE SQL query for the entity when Save Changes is called.

let
The let keyword is used to introduce a temporary variable within a LINQ query to store results or expressions.
var query = from e in context.Employees
            let fullName = e.FirstName + " " + e.LastName
            select new { e.Id, FullName = fullName };

Spatial Data Type
Spatial data types are used to store geometric and geographic data such as points, lines, polygons, etc., in a relational database. These types are particularly useful in applications that deal with geographic information systems (GIS) or spatial operations (like calculating distances, areas, or performing geographic queries).
context.CricketGrounds.Add(new CricketGround() {

Seeding data
The most common way to seed data in EF Core is through the OnModelCreating method in the DbContext class. This method allows you to configure the model and insert initial data into the tables.
using Microsoft.EntityFrameworkCore;

public class AppDbContext : DbContext
{
    public DbSet<Student> Students { get; set; }
    public DbSet<Course> Courses { get; set; }

    public AppDbContext(DbContextOptions<AppDbContext> options) : base(options) { }

    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        // Seeding data for the "Students" table
        modelBuilder.Entity<Student>().HasData(
            new Student { StudentId = 1, Name = "John Doe", Age = 20 },
            new Student { StudentId = 2, Name = "Jane Smith", Age = 22 },
            new Student { StudentId = 3, Name = "Sam Brown", Age = 21 }
        );

        // Seeding data for the "Courses" table
        modelBuilder.Entity<Course>().HasData(
            new Course { CourseId = 1, CourseName = "Math 101", Credits = 3 },
            new Course { CourseId = 2, CourseName = "English 101", interfaceCredits = 3 },
            new Course { CourseId = 3, CourseName = "Science 101", Credits = 4 }
        );
    }
}
Note: You must ensure that the primary key values are set correctly, as EF Core will not auto-generate them for seeded data when using HasData().
HasData(): This method is used to insert predefined data into the database
