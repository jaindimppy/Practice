Google penalizes websites that use the old HTTP. If a site is on HTTP, Google will rank it lower in search results. A stark Warning Triangle icon (⚠️).
Branded, bright red text that explicitly reads "Not Secure" or "Your connection to this site is not private.
When a user clicks it, the browser confirms that the 'Connection is secure.' That is HTTPS at work. It tells our users two things: their data is 100% encrypted so no one can spy on it, and the browser guarantees they are on our official, legitimate website.

    public virtual void ShowMessage()
    {

    }
}

public class Child : Parent
{
    // 'override' means the Child is replacing the Parent's message with its own
    public override void ShowMessage()
    {
        Console.WriteLine("Hello from the Child Class!");
    }
}

public class Program
{
    public static void Main()
    {
        Parent myParent = new Parent();
        myParent.ShowMessage(); // Output: Hello from the Parent Class!

        Parent myChild = new Child();
        myChild.ShowMessage();  // Output: Hello from the Child Class!
    }
}

using System;

// ABSTRACTION: We define the "what" without the "how"
public abstract class Test
{
    // Abstract methods have NO body {}
    public abstract void Getdata(); 
}

// METHOD OVERRIDING: Child class provides the specific implementation
public class My : Test
{
    // Must use 'override' and match the method name exactly
    public override void Getdata() 
    {
        Console.WriteLine("Getting data from the Child (My) class!");
    }
}

class Program
{
    static void Main()
    {
        // ERROR FIX: 'Test obj = new Test();' is illegal because Test is abstract.
        // Instead, we use Polymorphism: Parent reference pointing to Child object.
        Test obj = new My();
        
        // This calls the overridden method in the 'My' class
        obj.Getdata(); 
    }
}

Explain the difference between UNION and UNION ALL. Which one is faster and why?
UNION vs. UNION ALL
Both operators combine the result sets of two or more SELECT queries into a single output.

UNION: Combines the results and removes duplicate rows.

UNION ALL: Combines the results and keeps all rows, including duplicates.

Which is faster? UNION ALL is significantly faster.
To remove duplicates, UNION forces the database engine to perform a distinct/sort operation behind the scenes to scan for identical rows. UNION ALL simply appends the datasets together and streams them back without any extra processing or memory consumption.

*What is a Deadlock, and how does a database engine detect and resolve one? What design patterns can you enforce in your backend data access layer to minimize deadlock occurrences?
A Deadlock is a situation where two or more concurrent database transactions are permanently blocked because each transaction holds a lock on a resource that the other transaction needs to proceed. Neither can move forward, and neither will release the lock it currently holds.

The Victim Selection: The engine picks one of the transactions to be the "Deadlock Victim." It usually selects the transaction that is the cheapest to kill (the one that has written the least amount of data to the log file, minimizing rollback cost).
The Rollback: The engine forcibly kills the victim's database connection and rolls back all of its uncommitted changes. This automatically releases all the locks that the victim was holding.
The Survivor Wins: With the locks released, the surviving transaction instantly gets the resource it was waiting for and completes its work successfully.

Use Optimistic Concurrency
Example
Suppose two users edit the same record:
Both read the record (no locks).
User A updates → row version increments.
User B tries to update → version mismatch → update fails, retry needed.
No deadlock, just a retry.

using System;

public class Program
{
    public static bool IsAnagram(string str1, string str2)
    {
        // 1. If lengths are different, they can't be anagrams
        if (str1.Length != str2.Length) 
            return false;

        // 2. Convert to char array and sort both
        char[] charArray1 = str1.ToLower().ToCharArray();
        char[] charArray2 = str2.ToLower().ToCharArray();

        Array.Sort(charArray1);
        Array.Sort(charArray2);

        // 3. Compare the sorted strings
        return new string(charArray1) == new string(charArray2);
    }

    public static void Main()
    {
        Console.WriteLine(IsAnagram("listen", "silent")); // True
        Console.WriteLine(IsAnagram("apple", "pappl"));   // False
    }
}
